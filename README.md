# Our Little Dreamboard

[프로젝트 개요] 부부가 함께 살면서 해보고 싶은 것들을 기록하고 이뤄나가는 '공동 버킷리스트 보드' 웹 어플리케이션을 만들어주세요. 따뜻하고 감성적인 분위기의 디자인이 필요합니다.

[핵심 기능]

버킷리스트 추가 기능: 상단에 '새로운 버킷리스트 추가하기' 버튼이 있고, 클릭하면 모달(Modal) 창이 뜹니다. 모달 창에서는 [제목], [간단한 설명], [목표 연도]를 입력해 카드를 생성할 수 있습니다.

보드(Board) 분리: 화면은 크게 두 가지 영역 또는 탭으로 나뉩니다.

🏃‍♂️ 우리의 꿈 (To-Do)

✨ 이룬 꿈 (Done)

상태 변경 및 애니메이션: '우리의 꿈' 영역에 있는 카드 하단의 [완료하기] 버튼을 누르면, 해당 카드가 '이룬 꿈' 영역으로 이동합니다. 이때 화면에 꽃가루가 터지는(Confetti) 축하 애니메이션 효과를 넣어주세요.

수정 및 삭제: 등록된 카드를 클릭하면 내용을 수정하거나 삭제할 수 있어야 합니다.

[디자인 및 UI/UX 가이드]

전체 테마: 따뜻하고 코지(Cozy)한 느낌의 파스텔 톤 (예: 웜 아이보리 배경, 연한 코랄 또는 민트색 포인트).

카드 디자인: 각 버킷리스트 항목은 예쁜 폴라로이드 사진 느낌이나 모서리가 둥근 귀여운 포스트잇 형태의 카드로 디자인해 주세요.

반응형 웹: 부부가 자기 전 침대에서 스마트폰으로 함께 볼 수 있도록 모바일 화면에 완벽하게 최적화된 반응형 디자인으로 만들어주세요.

아이콘 활용: 글씨만 있는 것보다 어울리는 이모지나 심플한 아이콘을 적절히 배치해서 아기자기한 느낌을 살려주세요.
